## 关于

本项目是由 [LiteyukiBot-6](https://github.com/LiteyukiStudio/LiteyukiBot) 延申而来的 Rust 重构项目, 在保留原有轻量化特点的同时又迎合 AI 时代浪潮.

## 特点

- Rust 开发: 高效运行
- 多线程处理: 避免*一核有难, 七核围观*
- Websocket & SSE & TCP-Http三段兼容: 总有一个接口适合
- TUI & Docker & Tauri2-GUI: 想要什么风格都可以
